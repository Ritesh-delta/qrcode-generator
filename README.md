# QR Code Generator 🧾

A simple Python project to generate QR codes from text or URLs.

---

## ✨ Features
- 🔗 Generate QR codes from URLs
- 📝 Generate QR codes from text
- 🎨 Custom QR colors
- ⚡ Automatic QR version detection
- 💾 Save QR code as image

---

## 🛠️ Technologies Used
- 🐍 Python
- 📦 qrcode library
- 🖼️ Pillow (PIL)

---

## 📥 Installation

```bash
pip install qrcode[pil]
```

---

## ▶️ Run the Project

```bash
python generator.py
```

---

## 📸 Example

Enter text or URL:

```text
https://youtube.com
```

QR code will be saved as:

```text
auto_qr.png
```
